# Add SARIF output format support for GitHub code scanning

## Context
In src/report.ts and src/cli.ts, waveforge currently supports text, json, and markdown report formatters. GitHub code scanning workflows consume Static Analysis Results Interchange Format (SARIF) files to display automated annotations directly on repository pull request diffs. Providing a SARIF formatter enables automated pipelines to upload waveforge validation findings to GitHub Advanced Security dashboards.

## Requirements
- Add a new formatter function `formatSarif(report)` in src/report.ts implementing valid SARIF 2.1.0 JSON output.
- Map rule statuses (FAIL, WARN) to SARIF severity levels (error, warning).
- Support `--format=sarif` and `--sarif` flags in the CLI within src/cli.ts.
- Add unit tests verifying SARIF JSON schema structure and severity mappings in test/report.test.ts.
