## Context

Currently, some fix messages use imperative phrasing like 'Add a license file' while others use descriptive text. Harmonizing the message copy ensures consistency for Wave participants reading CLI and GitHub Action outputs. Updating this user-facing text improves developer experience without affecting rule evaluation logic.

- Ensure every fix hint concisely explains the corrective action in one sentence.
- Verify that test assertions in test/repo-checks.test.ts continue to pass with the updated copy.
