# Implement check R13 for automated testnet deployment scripts

## Context
In src/repo/ and src/repo/index.ts, our repository readiness suite checks contracts, tests, and CI setups, but does not currently check whether projects provide reproducible deployment scripts. Many Wave submission reviewers look for shell scripts or npm tasks (such as `scripts/deploy.sh` or `deploy:testnet`) that automate contract deployment to Stellar testnet. Adding check R13 will detect common deployment scripts and guide teams to provide clear deployment tooling.

## Requirements
- Add check module `src/repo/r13.ts` that inspects `scripts/` and `package.json` scripts for deployment commands.
- Report PASS when an executable deployment script or testnet deployment npm script is discovered.
- Report WARN with actionable guidance when no automated deployment script is found.
- Wire check R13 into `src/repo/index.ts` so it runs alongside other repository checks.

## Done when
- [ ] Check R13 is implemented in src/repo/r13.ts following the CheckResult interface.
- [ ] Discovery logic recognizes deployment scripts in scripts/ and package.json entries.
- [ ] Unit tests in test/repo-checks.test.ts verify PASS and WARN branches.
- [ ] Check R13 is exported and registered in src/repo/index.ts.

## Files to touch
