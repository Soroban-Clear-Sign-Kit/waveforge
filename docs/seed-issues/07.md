# Add template scaffolding with --fix mode for missing community files

## Context
In src/cli.ts and src/repo/r5.ts, rule R5 detects missing GitHub issue forms and missing config.yml settings. While waveforge currently suggests fixes in console text, developers must manually copy templates into their .github/ISSUE_TEMPLATE directories. Providing a `--fix` flag on the `repo` command will allow waveforge to scaffold missing standard issue templates (bug, feature, spike) and enable strict issue configuration automatically.

## Requirements
- Introduce a `--fix` flag to the `repo` CLI command in src/cli.ts.
- When `--fix` is passed and R5 detects missing templates, generate recommended template files under `.github/ISSUE_TEMPLATE/`.
- Never overwrite existing customized templates unless an explicit subflag or force option is supplied.
- Add test coverage in test/cli.test.ts verifying template file creation when running with `--fix`.

## Done when
- [ ] The `--fix` flag is recognized by parseArgs in src/cli.ts.
- [ ] Missing issue form templates and config.yml are generated in target directories.
- [ ] Existing issue templates are preserved and not overwritten without explicit confirmation.
- [ ] Automated tests in test/cli.test.ts assert that running with `--fix` resolves R5 warnings.

## Files to touch
- src/cli.ts
- src/repo/r5.ts
- src/templates/
- test/cli.test.ts

## Suggested execution
1. Define template content generators for standard issue forms in src/templates/.
2. Connect the template generator to the R5 resolution step in src/cli.ts.
3. Add safety checks preventing unintended overwrites of existing files.
4. Add CLI test cases running against a temporary test repository.
