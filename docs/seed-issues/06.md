# Spike check R12 for state-changing authorization analysis

## Context
In src/repo/r7.ts and src/repo/index.ts, our Soroban checks verify basic crate setup and CI commands, but do not inspect contract function signatures for authorization calls. We need a spike to investigate whether static analysis or regex pattern matching can reliably detect missing require_auth invocations in public state-changing functions without full Rust AST compilation. This research spike produces a prototype and design notes for future rule R12.

## Requirements
- Research AST parsing versus regex heuristics for detecting public mutating functions in Rust contracts.
- Document who must authorize state changes in Soroban contracts using require_auth.
- Outline testing requirements for contract code using cargo test.
- Document build verification requirements using stellar contract build and Wasm size checks.
- Produce a spike report and prototype script in docs/ analyzing false positive rates across example contracts.
